# パピルのタイピング島

パピルと一緒に、指づかいとローマ字入力を冒険形式で練習する学習ゲームです。

## 遊び方

`index.html` をブラウザで開くか、静的Webサーバーから配信してください。音声は最初のボタン操作後に再生され、タブやアプリがバックグラウンドに移ると自動停止します。

## 動作確認

```bash
npm test
npm run check
```

## パピルタクシー（知育ドライブゲーム）

`taxi/index.html` は、クレイジータクシー風の知育ゲームです。おきゃくさんをのせて、問題の答えが書かれた行き先へ制限時間内に届けます（たしざん・ひきざん／かけざん／かんじのよみ／えいたんご）。矢印キーまたは WASD で運転、スマホは画面のボタンで操作します。
